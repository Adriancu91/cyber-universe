# P6-01c — Stick-uri formatate în Windows (după testul 2, comanda C-4)

**Scop:** `/usb` se montează și pe un stick formatat în Windows (MBR, sau FAT32 direct fără tabelă), nu doar pe imaginea GPT.

**Pași**
1. `fs/part.rs`: dacă sectorul 0 e chiar un sector de pornire FAT („superfloppy”) → tot discul; MBR: tipurile FAT cunoscute, apoi
   orice intrare al cărei prim sector e un sector de pornire FAT.
2. Stick-uri reale: TEST UNIT READY + REQUEST SENSE (care șterge „unit attention”) și reîncercări ~3 s înainte de READ CAPACITY.
3. Motivul pentru care `/usb` nu s-a montat e ținut minte și arătat de `hw`.

**Fișiere:** `kernel/src/fs/{part,mod}.rs`, `kernel/src/drivers/usb/{storage,mod}.rs`, `kernel/src/shell/mod.rs`, `tools/build.sh`.

**Test:** scenariul `usb-floppy` (imaginea `build/floppy.img`, FAT32 fără tabelă, ca stick USB → `/usb`, fișierele corecte).

**Surse:** specificația Microsoft FAT (BPB), SCSI SPC (REQUEST SENSE), USB Mass Storage Bulk-Only Transport.
