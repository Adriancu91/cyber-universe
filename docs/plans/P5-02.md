# P5-02 — UDP și DHCP

**Scop:** nucleul își ia singur adresa, masca, ruta implicită și serverul DNS de la rețea.

**Pași**
1. UDP: trimitere/primire cu porturi, sume de control (cu pseudo-antetul IPv4).
2. Client DHCP (DISCOVER → OFFER → REQUEST → ACK), reînnoire la jumătatea duratei.
3. `net` în shell arată adresa, ruta și DNS-ul primite.

**Fișiere:** `kernel/src/net/{udp,dhcp}.rs`.

**Test:** scenariu `dhcp`: QEMU (rețeaua „user”) dă 10.0.2.15, ruta 10.0.2.2 și DNS 10.0.2.3; jurnalul le arată.

**Riscuri:** servere DHCP reale care cer opțiuni în plus (client id, nume) — de verificat pe ThinkPad după P3-09.

**Surse:** RFC 768 (UDP), RFC 2131 și RFC 2132 (DHCP).
