# P6-23 — Permisiuni pe program (comanda C-22, partea 2)

## Scop
Un program declară ce grupuri de apeluri („promisiuni”) și ce căi („căi vizibile”) folosește; după declarare nu le mai poate lărgi.
`/usb/claude.key` și `/usb/github.token` se văd doar de programele care le cer explicit.

## Pași
1. Apeluri noi: `promite(masca)` (doar poate micșora masca) și `vede(cale, drepturi)` (după primul apel, doar căile listate sunt vizibile;
   după `vede("", 0)` lista se închide).
2. Nucleul verifică la fiecare apel de sistem masca procesului; la fișiere, calea față de lista vizibilă.
3. Căile secrete (`/usb/claude.key`, `/usb/github.token`) sunt ascunse implicit oricărui program care nu le-a cerut prin `vede`.
4. Aplicația Claude și `gh-trimite` le cer explicit; restul programelor nu.

## Test
Program de test: fără `vede` cheia → eroare; cu `vede` pe cheie → citire reușită; după `promite` fără rețea, apelul de rețea → eroare.
