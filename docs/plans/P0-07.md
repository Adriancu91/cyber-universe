# P0-07 — Ieșire automată din QEMU

**Scop:** la finalul testului nucleul închide QEMU singur, cu cod de succes sau eșec.

**Pași**
1. Adaugă la `test.sh`: `-device isa-debug-exit,iobase=0xf4,iosize=0x04`.
2. În nucleu, `kernel/src/qemu.rs`: `exit_qemu(code)` scrie la portul `0xf4`.
   Convenție: `Success = 0x10` → QEMU iese cu **33**; `Failed = 0x11` → iese cu **35**.
3. Funcția se apelează doar în modul test (feature Cargo `qemu-test`), ca pe hardware real să nu scrie la portul `0xf4`.
4. `test.sh`: 33 = trecut, 35 = eșuat, 124 = timeout, alt cod = eroare QEMU.

**Fișiere:** `kernel/src/qemu.rs`, `kernel/Cargo.toml` (feature), `tools/build.sh` (opțiune `--test`), `tools/test.sh`.

**Test:** `test.sh` se termină în sub 10 secunde cu cod 0.

**Riscuri:** pe hardware real portul `0xf4` poate aparține altui dispozitiv — de aceea feature-ul.

**Surse:** documentația QEMU `isa-debug-exit`; prototipul (cod 33 verificat).
