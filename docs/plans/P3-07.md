# P3-07 — Stick USB (Mass Storage) ca dispozitiv de blocuri

**Scop:** fișierele de pe un stick USB se pot citi (`/usb`).

**Pași**
1. Dispozitive clasa 08, subclasa 06 (SCSI), protocol 0x50 (Bulk-Only Transport).
2. Comenzi SCSI prin CBW/CSW: `INQUIRY`, `READ CAPACITY(10)`, `READ(10)`.
3. `UsbDisk` implementează `BlockDevice`; montare FAT32 la `/usb`.

**Fișiere:** `kernel/src/drivers/usb/storage.rs`, `kernel/src/fs/mod.rs`.

**Test:** scenariu `usb-storage`: QEMU cu `disk.img` ca `usb-storage` → `/usb` montat, suma fișierului de 100 KiB corectă.

**Riscuri:** unele stick-uri cer `TEST UNIT READY` repetat după pornire.

**Surse:** USB Mass Storage Class — Bulk-Only Transport 1.0; SCSI Primary/Block Commands (descrieri publice).
