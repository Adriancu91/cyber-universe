# P4-04 — Server grafic: ferestre și cursor

**Scop:** ferestre care se pot deschide, muta, suprapune și închide cu mouse-ul.

**Pași**
1. Lista de ferestre (ordine pe adâncime), focus, bară de titlu cu buton de închidere.
2. Compunere: fiecare fereastră are bufferul ei; serverul le compune în `Canvas` doar unde s-a schimbat ceva.
3. Cursorul mouse-ului; tragerea ferestrelor de bara de titlu.
4. Evenimentele de tastatură merg la fereastra cu focus.

**Fișiere:** `kernel/src/ui/server.rs`, `kernel/src/ui/README.md`.

**Test:** scenariu `windows`: două ferestre create din test, a doua mutată prin evenimente de mouse trimise de QEMU, captură → pozițiile corecte (pixeli verificați).

**Riscuri:** viteza pe ecrane mari fără accelerare: compunere doar pe zone murdare (P4-02).

**Surse:** design propriu.
