# P6-85 — C-116 (partea OS): laptopul ASUS TUF F15 (GA106) — recunoaștere, „trezirea minimă” la `gpu tur`, modelul din SMBIOS în `hw`

**Scop:** laptopul ASUS TUF F15 (RTX 3060 Laptop, GA106, `10de:2520`) devine a doua mașină de test (decizia lui Adrian, C-116).
Firmware-ul laptopului lasă placa cu Memory Space oprit, deci nimic nu se poate citi din ea. Cyber-GPU a pregătit (în SIMULARE)
recunoașterea GA106 doar-citire și „trezirea minimă” (o singură scriere în registrul Command al PCI, repusă la final).
OS-ul: (1) leagă cyber-gpu `6b6bb38`; (2) `gpu identifica` / `gpu tur` recunosc laptopul; (3) `gpu tur --trezire` pe stick-ul
de test, după `DA`; (4) `gpu lant` și tot ce scrie în registre rămân refuzate pe GA106; (5) `hw` arată modelul calculatorului din SMBIOS.

**Pași**
1. `kernel/Cargo.toml` + `CYBER_GPU_REV` + scenariile: cyber-gpu `6b6bb38` (conține și `45dfc77` = motivul pasului eșuat pe stick,
   `e49ca76` = varianta 1 implicită, `3404313` = starea plăcii după I7 eșuat). Textele „ca os-283” devin „varianta implicită 1”.
2. `gpu identifica`: `probe_config_ampere` (GA104 sau GA106); cu Memory Space oprit, textul vine din bibliotecă (`MEMORY_SPACE_OFF`).
3. `gpu tur`: pe GA106 cu Memory Space oprit → refuz curat cu îndemnul spre `gpu tur --trezire`; pe GA104 neschimbat.
4. `gpu tur --trezire`: doar în build-ul `gpu-scrie`, după `DA`; adaptor de configurație care lasă să treacă DOAR bitul 1 din Command;
   `run_tour_awake` cu fereastra BAR0 doar-citire și jurnalul pe stick; după: `trimite`. Pe stick-ul normal → refuz, nimic scris.
   `gpu tur --trezire --sim`: același drum pe modelul gpu-sim al laptopului (`SimConfig::ga106_laptop_asus`).
5. `gpu lant` / `gpu recupereaza` / `gpu i6` pe GA106: refuz cu motivul (C-116 pasul 3 cere un DA separat).
6. `hw`: rândul `calculator: <producător> <produs> (<versiune>)` din SMBIOS tipul 1 (+ placa de bază, tipul 2), prin cererea SMBIOS a lui Limine.
7. Scenariu QEMU `gpu-ga106` (+ `-smbios type=1,...` ca să se vadă rândul în `hw`).

**Fișiere:** `kernel/Cargo.toml`, `kernel/Cargo.lock`, `kernel/src/drivers/gpu.rs`, `gpu_i6.rs`, `gpu_tur.rs`, `kernel/src/shell/mod.rs`,
`kernel/src/hw/` (SMBIOS), `tests/scenarios.txt`, `kernel/src/drivers/README.md`.

**Test:** `tools/test.sh gpu-ga106 gpu gpu-sim gpu-tur gpu-var gpu-i6 gpu-rec gpu-scrie gpu-ro boot shell`; CI verde → Release.

**Riscuri:** pe laptop netestat (doar SIMULARE). Pe un laptop hibrid (Optimus), pornirea Memory Space e ce face orice driver (Linux
`pci_enable_device`), dar placa poate fi oprită de ACPI → atunci BOOT_0 = FFFFFFFF și turul se oprește (Command repus).
SMBIOS poate lipsi pe unele calculatoare → rândul spune „SMBIOS absent”.

**Surse:** nota cyber-gpu `integration/cyber-universe/C-116_ga106-trezire.md`; specificația DMTF SMBIOS 3.x (structurile de tip 1 și 2);
protocolul Limine (cererea SMBIOS); specificația PCI (registrul Command, bitul 1 Memory Space).
