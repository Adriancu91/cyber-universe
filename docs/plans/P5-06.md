# P5-06 — HTTPS de bază (client TLS 1.3)

**Scop:** un program descarcă o pagină prin HTTPS și verifică certificatul serverului.

**Pași**
1. **Decizie pentru Adrian (înainte de cod):** criptografia (SHA-256, HMAC/HKDF, X25519, AES-GCM sau ChaCha20-Poly1305,
   verificarea certificatelor RSA/ECDSA) — scrisă de noi sau o bibliotecă open-source cu licență compatibilă MIT
   (ex. crate-uri RustCrypto, licență MIT/Apache) folosită ca dependență, nu copiată. Notă în DECISIONS.md.
2. TLS 1.3 client minimal (o singură suită), HTTP/1.1 GET.
3. Certificatele rădăcină: o listă mică în initrd; ceasul (RTC) pentru valabilitate.

**Fișiere:** `user/src/tls/`, `user/src/bin/fetch.rs` (sau modul separat), `docs/DECISIONS.md`.

**Test:** scenariu `https`: server HTTPS de test pe gazdă (`python3` cu certificat generat la test, rădăcină pusă în
initrd-ul de test); programul descarcă pagina; un certificat greșit e refuzat.

**Riscuri:** criptografia scrisă de mână e ușor de greșit — vectori de test oficiali (RFC 8448, NIST) obligatorii.

**Surse:** RFC 8446 (TLS 1.3), RFC 8448 (exemple), RFC 5280 (certificate), RFC 7748 (X25519), RFC 8439 (ChaCha20-Poly1305).
