# P5-06 — Client TLS 1.3 (biblioteca `tls/`)

> Împărțită la 2026-10-20: P5-06 = biblioteca TLS 1.3, testată pe gazdă cu un server OpenSSL; P5-16 = HTTPS în OS.
> Decizia pentru criptografie: D-011 (scrisă de noi, P5-10 … P5-15).

**Scop:** o bibliotecă `no_std`, fără heap, care face strângerea de mână TLS 1.3 ca un client și apoi trimite/primește
date criptate, peste orice „țeavă” de octeți (trăsătura `Io`): în teste un socket TCP de pe gazdă, în OS `net::TcpStream`.

**Pași**
1. Înregistrările (RFC 8446 §5): antetul de 5 octeți, înregistrări criptate cu ChaCha20-Poly1305 (nonce = iv XOR număr),
   tipul real la final, umplutura de zerouri; ChangeCipherSpec de compatibilitate ignorat.
2. ClientHello: o singură suită (TLS_CHACHA20_POLY1305_SHA256), grupul X25519, numele serverului (SNI), algoritmii de
   semnătură (ECDSA P-256 SHA-256, RSA-PSS SHA-256/384/512; RSA PKCS#1 doar pentru certificate).
3. ServerHello → programarea cheilor (§7.1) cu transcrierea SHA-256; EncryptedExtensions, Certificate (lanțul verificat
   cu `x509::verify_chain`), CertificateVerify (§4.4.3), Finished (HMAC). Apoi Finished-ul clientului și cheile de aplicație.
4. Date: `send`, `recv` (ignoră NewSessionTicket), `close` (close_notify). Orice abatere = eroare, conexiunea se oprește.

**Fișiere:** `tls/` (crate nou: `src/lib.rs`, `src/record.rs`, `src/client.rs`), `tls/tests/` (server de test Python +
certificate de test), CI.

**Test:** pe gazdă (`cd tls && cargo test --release`): un server Python `ssl` (OpenSSL) cu TLS 1.3 pe localhost;
clientul descarcă o pagină; refuz pentru certificat de la o rădăcină necunoscută, nume greșit, certificat expirat.

**Riscuri:** mesaje de handshake împărțite în mai multe înregistrări (sau mai multe într-una); HelloRetryRequest (îl refuzăm:
oferim doar X25519, pe care serverele îl acceptă); ordinea cheilor în transcriere.

**Surse:** RFC 8446, RFC 8448 (exemple), RFC 8439, RFC 7748, RFC 5280.
