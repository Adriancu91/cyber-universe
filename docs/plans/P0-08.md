# P0-08 — Integrare continuă pe GitHub Actions

**Scop:** la fiecare push pe `main` și pe ramuri `wip/*`, GitHub construiește și testează automat.

**Pași**
1. `.github/workflows/ci.yml`, `runs-on: ubuntu-24.04`.
2. Pași: checkout → `apt-get install qemu-system-x86 ovmf xorriso` → `rustup toolchain install nightly -c rust-src --target x86_64-unknown-none` →
   cache pentru `~/.cargo` și `kernel/target` → `tools/env-check.sh` → `tools/build.sh --test` → `tools/test.sh`.
3. La eșec: încarcă `build/serial.log` ca artefact.
4. Adaugă insigna CI în `README.md`.

**Fișiere:** `.github/workflows/ci.yml`, `README.md`.

**Test:** primul push după sarcină are rularea CI verde (verifică cu `gh run list` / `gh run view`).

**Riscuri**
- Actions dezactivat pe repo: notează în BLOCKERS, „Nevoie de Adrian: da — Settings → Actions → Allow”.
- Limite de minute pentru repo privat: construcția trebuie să rămână sub ~3 minute (cache).

**Surse:** documentația GitHub Actions.
