# P6-206 — agentul de bord, pasul 3b: `agent veghe` pornit singur de lista automată (C-166)

**Scop:** C-166 pasul 3 cere starea live „în timpul testelor, cursei de noapte și antrenărilor”. P6-204 a făcut
`agent veghe` (comanda); aici lista automată (`auto/teste.txt`) îl pornește în fundal și îl oprește la sfârșit.

**Pași:**
1. Lista automată: înaintea primului `test-placa` / `lucrare` din listă, dacă pe stick există `claude.cheie` sau
   `github.token`, pornește `/bin/agent veghe` în fundal (`proc::spawn_path` fără așteptare; argumentele implicite).
2. La sfârșitul listei (sau la oprirea ei de paza de timp): `proc::kill` pe agent, apoi o ultimă tură scurtă
   (`agent veghe 0 1`) ca `live/os-agent.md` să arate starea de la sfârșit.
3. Rândul de jurnal `auto: agent veghe pornit (id N)` / `oprit`.
4. Test QEMU: lista `auto` cu imitațiile API + GitHub: agentul pornit, o tură în timpul listei, oprit la final.

**Fișiere:** `kernel/src/shell/auto.rs`, `kernel/src/main.rs` (testul), `tests/scenarios.txt`.

**Nou pentru placă:** nimic.

**Riscuri:** agentul în fundal folosește rețeaua în timpul testelor de placă (doar HTTPS, ca `gh-trimite`); dacă se
dovedește că încurcă un test, centrul îl poate opri scoțând cheia sau tokenul.

**Surse:** C-166 pasul 3; P6-204; P6-41 (lista automată).

**Făcut (2026-11-25):** ca în pași; testul QEMU = scenariul `auto-agent` (build `test-auto-agent`, imitațiile API + GitHub prin
`tools/before-auto-agent.sh`, disc `tests/disk/auto-agent/`), comanda de test `test-asteapta <fisier> <secunde>`. Abatere de la
plan: la oprirea de paza de timp nu se face tura finală (repornirea vine din firul pazei). Tura finală e un proces nou, deci
vede ca „noi” toate avertismentele din ultimele 60 de rânduri ale jurnalului (rezumatul de la sfârșit poate spune ABATERE).
