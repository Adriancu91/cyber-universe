# P6-87 — C-117 pasul 2: partea NVIDIA în `analiza` (turul de citire Cyber-GPU)

**Scop:** C-117 cere ca inventarul `analiza` să conțină, pentru placa NVIDIA, ce citește Cyber-GPU **doar citire, prin lista sigură
C-54**: BOOT_0/BOOT_42, GFW, antetele VBIOS, FWSEC, VRAM/WPR2 (faptele I6). Exact asta face deja `gpu tur` (0 scrieri, pe lista albă
a buclei automate). Pasul 2 pune faptele turului în inventar, ca o componentă `gpu_registers` legată de funcția PCI a plăcii.

**Pași**
1. `hw/uhl.rs`: `GpuTour` (adresa PCI, simulare da/nu, rândurile turului); `tour_facts` citește rândurile `fapt <cheie> = <valoare>`;
   componenta `gpu:0000:<adresă>` cu `facts` (obiect cheie → valoare), `fact_count`, `writes_to_board` (din rândul de scrieri al turului:
   CONFIRMED „0”), `tour_lines`, `vbios_image` = NOT_TESTED (imaginea nu intră în inventar); fără fapte → UNKNOWN + motivul (ex. GA106 cu
   Memory Space oprit → `gpu tur --trezire`). Pe funcția PCI: `nvidia_registers` trimite la componentă.
2. `shell/analiza.rs`: dacă există o placă NVIDIA (clasa 03), rulează `gpu_tur::tour()` (același drum ca `gpu tur`). `analiza --sim`
   (doar build-urile de test cu gpu-sim): turul pe modelul plăcii workstation, marcat SIMULARE.
3. `report.txt`: un rând pentru placă (cip, fapte, GFW, scrieri).

**Fișiere:** `kernel/src/hw/uhl.rs`, `kernel/src/shell/analiza.rs`, `kernel/src/shell/mod.rs`, `tests/scenarios.txt`, `kernel/src/hw/README.md`.
