# P0-01 — Verificarea și instalarea mediului

**Scop:** toate uneltele necesare există și versiunile sunt notate în `STATE.md`.

**Pași**
1. Verifică: `rustup`, `cargo`, `qemu-system-x86_64`, `xorriso`, `make`, `git`, `curl`, fișierele OVMF din `/usr/share/OVMF/`.
2. Dacă lipsește ceva și ai drept de instalare (sesiune cloud / Ubuntu):
   `sudo apt-get install -y qemu-system-x86 ovmf xorriso make curl` (sau fără `sudo` dacă rulezi ca root).
3. Rust: `rustup toolchain install nightly --profile minimal -c rust-src`.
4. Creează `tools/env-check.sh` care face verificările de la pasul 1 și iese cu cod ≠ 0 dacă lipsește ceva.
5. Scrie versiunile în tabelul din `STATE.md`.

**Fișiere:** `tools/env-check.sh`, `docs/STATE.md`.

**Test:** `tools/env-check.sh` returnează 0.

**Riscuri**
- Fără drept de instalare (laptopul lui Adrian, fără parolă `sudo`): notează în BLOCKERS cu comanda exactă din `PREGATIRE.md` pas 4, „Nevoie de Adrian: da”.
- Calea OVMF diferă pe alte distribuții: caută cu `find / -name 'OVMF_CODE*.fd' 2>/dev/null`.
