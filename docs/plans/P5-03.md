# P5-03 — DNS (rezolvarea numelor)

**Scop:** un nume (ex. `example.com`) devine adresă IPv4, cu memorie temporară (cache) după TTL.

**Pași**
1. Cerere DNS tip A peste UDP la serverul primit prin DHCP; ID aleator, verificarea răspunsului.
2. Cache cu expirare; reîncercare și timp limită.
3. Comanda `host <nume>` în shell.

**Fișiere:** `kernel/src/net/dns.rs`.

**Test:** scenariu `dns`: `tools/test.sh` pornește un mic server DNS de test pe gazdă (Python, răspunde fix pentru
`test.cyber`), iar QEMU e pornit cu `-netdev user,dns=...`/redirecționare către el; nucleul trebuie să obțină adresa fixă.
Fără acces la internet în test (CI).

**Riscuri:** rețeaua „user” a QEMU trimite DNS-ul la serverul gazdei; aranjamentul pentru serverul de test trebuie încercat întâi.

**Surse:** RFC 1034, RFC 1035.
