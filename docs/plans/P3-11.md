# P3-11 — Testul 2 pe hardware real (comanda C-2 din hub)

**Scop:** o singură poză să arate tot hardware-ul văzut de OS, și o listă scurtă pe înțeles pentru Adrian.

**Pași**
1. Comanda `hw` în shell: procesorul (CPUID), memoria, de cât timp merge, dispozitivele PCI cu driverul nostru
   (`[ahci]`, `[nvme]`, `[xhci]`, `[e1000]`, `[rtl8168]`, `[-]` = fără driver), USB, dacă `/disk` și `/usb` sunt montate, rețeaua.
2. Lista pentru Adrian (în `stare/cyber-universe.md` din hub și în raport): Esc → consola text, `hw`, `ls /disk`, `ls /usb`,
   tastatură USB externă, timpul de pornire, apoi (după P6-01) cablu de rețea + `net` + `ping`.

**Fișiere:** `kernel/src/shell/mod.rs`, `kernel/src/drivers/nic.rs`, `tests/scenarios.txt`, `docs/HARDWARE.md`.

**Test:** scenariul `shell` — `hw` arată `procesor:`, controlerul SATA cu `[ahci]`, placa e1000e cu `[e1000]`, `/disk: montat`.

**Riscuri:** pe un ecran mic lista PCI poate fi lungă (pe Lenovo ~20 de rânduri); consola text (Esc) are mai mult loc decât fereastra.

**Surse:** Intel SDM / AMD APM — instrucțiunea CPUID (frunzele 0 și 0x8000_0002…4), doar documentație.
