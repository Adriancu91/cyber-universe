# P4-07 — FAT32: scriere (fișiere noi, modificare, ștergere)

**Scop:** nucleul poate scrie pe partiții FAT32 (stick, disc): necesar pentru instalarea modulelor și pentru jurnalul salvat pe stick (P3-09).

**Pași**
1. Alocare de clustere (căutare în FAT, ambele copii ale FAT actualizate), FSInfo.
2. Scriere în fișiere existente, mărire, fișiere noi (nume scurte + LFN), directoare noi, ștergere.
3. `BlockDevice::write` în MemDisk, AHCI (`WRITE DMA EXT`), NVMe (`Write`), USB (`WRITE(10)`).
4. Protecție: o operație întreruptă nu strică restul (ordinea: date → FAT → director).

**Fișiere:** `kernel/src/fs/fat32.rs`, `kernel/src/block/mod.rs`, driverele de disc.

**Test:** scenariu `fatwrite`: pe discul de test (copie temporară) se creează, scriu, citesc și șterg fișiere; apoi `fsck.fat -n` pe imagine (rulat de `tools/test.sh` după QEMU) nu găsește erori.

**Riscuri:** stricarea datelor reale — scrierea e activă doar pe discuri marcate explicit (stick/discul de test), niciodată implicit pe discul intern până nu e testată mult.

**Surse:** Microsoft „FAT32 File System Specification” (fatgen103).
