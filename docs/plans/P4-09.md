# P4-09 — Aplicații de sistem: monitor sistem și fișiere

**Scop:** primele aplicații grafice, ca module: monitorul sistemului (procese, memorie, procesor) și managerul de fișiere.

**Pași**
1. Apeluri de sistem pentru informații: listă procese, memorie, timp procesor per fir.
2. Monitor: tabel actualizat la o secundă.
3. Fișiere: navigare în directoare, deschidere cu aplicația potrivită, copiere/ștergere (pe FAT32).

**Fișiere:** `user/src/bin/monitor.rs`, `user/src/bin/files.rs`, `kernel/src/syscall/`.

**Test:** capturi în QEMU cu valori verificate (ex. numărul de procese afișat = cel din nucleu).

**Surse:** design propriu.

**Notă la implementare (2026-10-20):** aplicațiile sunt programe în `/bin` (`monitor`, `files`); împachetarea lor ca module
instalabile din interfață vine cu P4-11. „Deschiderea cu aplicația potrivită” pornește programele; fișierele text se vor
deschide în editor (P4-10). Stiva programelor a crescut la 64 KiB (aplicațiile fără heap își țin listele pe stivă).
