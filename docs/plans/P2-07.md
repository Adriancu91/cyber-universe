# P2-07 — Sistem de fișiere în memorie (VFS + ramfs) cu fișiere inițiale

**Scop:** un strat comun pentru fișiere (VFS) și primul sistem de fișiere, în memorie: directoare, fișiere,
creare/citire/scriere/ștergere. Conținutul inițial vine dintr-o arhivă `tar` încărcată de Limine (initrd).

**Pași**
1. Interfața VFS: noduri (fișier/director), căi de forma `/bin/hello`, operații `lookup`, `read`, `write`, `create`, `list`, `remove`.
2. ramfs: arbore în heap.
3. Cititor de arhive `tar` (format USTAR) care populează ramfs la pornire.
4. `tools/build.sh` creează `initrd.tar` (programele din `user/` în `/bin`, un `/etc/motd`).

**Fișiere:** `kernel/src/fs/vfs.rs`, `kernel/src/fs/ramfs.rs`, `kernel/src/fs/tar.rs`, `kernel/src/fs/README.md`, `tools/build.sh`.

**Test:** scenariu `ramfs`: la pornire se listează `/bin` și `/etc`; `/etc/motd` se citește corect; un fișier creat,
scris, citit și șters; căi greșite (`/nu/exista`) dau eroare clară, fără panică.

**Riscuri:** antete tar cu nume lungi (prefix USTAR) — suportă doar USTAR, refuză restul cu mesaj.

**Surse:** specificația POSIX `ustar` (IEEE 1003.1, descrierea formatului `pax`/`ustar`); design propriu pentru VFS.
