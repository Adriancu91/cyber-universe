# P6-04 — Clientul API Claude (`/bin/claude` în linia de comandă)

**Scop:** `claude "întrebare"` în terminal trimite mesajul la API-ul Claude și afișează răspunsul.

**Pași**
1. Cheia se citește din `/usb/claude.key` (un singur rând). **Niciodată în repo, în jurnal sau pe ecran** (doar „cheie găsită: da/nu”).
2. Cerere `POST https://api.anthropic.com/v1/messages`, antete `x-api-key`, `anthropic-version`, `content-type: application/json`;
   corp JSON cu modelul, `max_tokens` și mesajele (P6-03); răspunsul: textul din `content`.
3. Erori pe înțeles: fără cheie, cheie greșită (401), prea multe cereri (429), fără rețea.
4. Test cu un server local care imită API-ul (HTTPS, rădăcina de test ca în scenariul `https`), fără cheie reală.

**Fișiere:** `user/claude/` (program), `tools/before-claude.sh` + server de test, `tests/scenarios.txt`.

**Test:** scenariul `claude-cli` (serverul de test răspunde; se verifică cererea primită: antetele și JSON-ul).

**Riscuri:** răspunsuri mari (memoria programelor), `transfer-encoding: chunked`, timpul de răspuns (zeci de secunde).

**Surse:** documentația publică Anthropic API (Messages).

**De la Adrian (la testul pe laptop):** fișierul `claude.key` pe stick, cu o cheie API (de preferat una cu limită mică de cheltuieli).
