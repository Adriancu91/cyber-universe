# P2-09 — Shell simplu: help, ls, cat, run, mem, reboot

**Scop:** după pornire apare un prompt pe ecran; comenzile de bază merg de la tastatură.

**Pași**
1. Editare de linie: caractere, Backspace, Enter (tastatura de la P1-10, firul shell-ului doarme în așteptarea tastelor — P2-03).
2. Comenzi: `help`, `ls [cale]`, `cat <fișier>`, `run <program> [arg...]`, `mem` (memorie liberă/folosită), `reboot` (prin ACPI sau controller-ul 8042), `uptime`.
3. Comandă necunoscută → mesaj clar.
4. Shell-ul rulează ca fir al nucleului în Faza 2 (mutat ca program separat mai târziu, dacă aduce un plus).

**Fișiere:** `kernel/src/shell/mod.rs`, `kernel/src/shell/README.md`, `kernel/src/main.rs`.

**Test:** scenariu `shell` cu taste trimise prin QEMU: `help` ↵ → lista de comenzi; `ls /bin` ↵ → `hello`, `cat`;
`mem` ↵ → linie cu memoria; `blabla` ↵ → „comandă necunoscută”.

**Riscuri:** `reboot` nu se poate verifica ușor în test (QEMU cu `-no-reboot` se oprește) — testează doar că QEMU iese.

**Surse:** design propriu; OSDev Wiki „Reboot” (metoda 8042) doar pentru idee.
