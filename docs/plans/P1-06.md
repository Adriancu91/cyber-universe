# P1-06 — Paginarea proprie

**Scop:** nucleul controlează tabelele de pagini: mapează și demapează adrese virtuale.

**Pași**
1. `kernel/src/mem/paging.rs`: citește `CR3` (tabelele create de Limine), accesează-le prin HHDM.
2. `map(virt, phys, flags)` creează la nevoie tabelele intermediare (PML4 → PDPT → PD → PT) cu cadre de la P1-05.
3. `unmap(virt)` + `invlpg`.
4. `translate(virt) -> Option<phys>`.
5. Flag-uri: prezent, scriere, utilizator, NX (bitul NX activ în `EFER`).

**Fișiere:** `kernel/src/mem/paging.rs`.

**Test:** mapează o pagină la o adresă nouă, scrie o valoare, o citește prin HHDM la adresa fizică; demapează și verifică (cu feature de test) că accesul produce page fault.

**Riscuri:** a nu demapa niciodată paginile nucleului sau ale HHDM; pentru acum păstrăm tabelele Limine și doar adăugăm.

**Surse:** Intel SDM Vol. 3A cap. 4; OSDev Wiki „Paging”.
