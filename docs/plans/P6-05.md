# P6-05 — Aplicația „Claude”: chat în fereastră

**Scop:** din meniul Start, „Claude” deschide o fereastră de chat: istoricul sus, caseta de scris jos, Enter trimite.

**Pași**
1. Program `/bin/claude-app` cu fereastră (ca Editorul): text cu diacritice, derulare, mesajele lui Adrian și ale lui Claude.
2. Conversația trimisă întreagă la fiecare cerere (P6-04); „se gândește…” cât așteaptă.
3. Salvare opțională a conversației în `/usb/claude/` (text).

**Fișiere:** `user/claude-app/`, desktopul (meniul Start), `tests/scenarios.txt`.

**Test:** scenariul `claude-app` cu serverul de test din P6-04: taste trimise de QEMU, răspunsul apare în fereastră (captură).

**Surse:** design propriu.
