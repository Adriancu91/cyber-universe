# P6-15 — `/usb` = stick-ul de pe care am pornit (comanda C-13, punctul 3)

**Scop:** pe workstation `/usb` a fost luat de cititorul de carduri intern fără card („Medium Not Present”, sense 2/3A), primul
Mass Storage găsit. Trebuie ales stick-ul cu sistemul.

**Pași**
1. Se încearcă toate dispozitivele Mass Storage, nu doar primul.
2. Cele care răspund cu sense 2/3A (fără mediu) se sar, cu un rând în `log usb`.
3. Dintre cele montate, se preferă discul care are `cyber.rw` și `VERSIUNE`; altfel primul montat.
4. Release separat (D-013).

**Fișiere:** `kernel/src/drivers/usb/` (mass storage), `kernel/src/fs/` (montarea `/usb`), `docs/USB.md`.

**Test:** QEMU cu două dispozitive de stocare USB: unul fără mediu (sau fără `VERSIUNE`) înaintea stick-ului → `/usb` = stick-ul.

**Riscuri:** timpul de pornire crește cu câte o așteptare TEST UNIT READY pe dispozitiv; limitat la ~5 s total.

**Surse:** USB Mass Storage Class Bulk-Only Transport 1.0; SCSI SPC (TEST UNIT READY, REQUEST SENSE, ASC 3A).
