# P6-89 — cyber-gpu `835f24d`: versiunea VBIOS (jetonul BIT 'i') în `gpu vbios` și în `analiza`

**Scop:** Cyber-GPU (sesiunea 96, C-116/C-117) a adăugat citirea versiunii VBIOS din jetonul BIT 'i' (0x69), în forma pe care o
arată Windows (`94.04.65.00.3e` pe workstation, `94.06.1E.00.23` pe laptop) — prima comparație automată Windows ↔ Cyber Universe
pe aceeași placă. Hub: „OS-ul leagă `835f24d`+ la următorul Release (nimic de schimbat în codul OS)”. Facem și propunerile 1–2 din
nota lor (`integration/cyber-universe/C-117_vbios-versiune.md`).

**Pași**
1. `kernel/Cargo.toml` + `Cargo.lock`: `rev = "835f24d"` (doar adăugări în bibliotecă); `CYBER_GPU_REV`.
2. `gpu vbios`: rândul `versiune VBIOS: …` (sau „necitita …”).
3. `analiza`: la componenta `gpu_registers`, proprietatea `vbios_version` (MEASURED, din faptul `vbios.versiune` al turului).
4. Scenariile: textele cu revizia, turul are acum 42 de fapte; `analiza-gpu` verifică `vbios_version`.

**Fișiere:** `kernel/Cargo.toml`, `kernel/Cargo.lock`, `kernel/src/drivers/gpu.rs`, `kernel/src/hw/uhl.rs`, `kernel/src/shell/analiza.rs`, `tests/scenarios.txt`.

**Test:** `gpu gpu-sim gpu-tur analiza-gpu` (SIMULARE: `vbios.versiune = 94.04.65.00.3e` în tur și în inventar), apoi toată suita.
