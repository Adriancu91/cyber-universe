# P3-01 — PCI: găsirea dispozitivelor

**Scop:** nucleul știe ce dispozitive are calculatorul (controlere de disc, USB, rețea), cu ID-urile lor, ca driverele să le poată găsi.

**Pași**
1. Tabela ACPI `MCFG` → zona ECAM (spațiul de configurare PCI Express mapat în memorie); fallback: porturile 0xCF8/0xCFC.
2. Enumerare magistrale/dispozitive/funcții (inclusiv punți PCI-PCI): vendor, device, clasă, subclasă, BAR-uri.
3. Listă globală + funcție `find(class, subclass, prog_if)` pentru drivere.
4. Comanda `lspci` în shell.

**Fișiere:** `kernel/src/pci/mod.rs`, `kernel/src/pci/README.md`, `kernel/src/acpi/` (MCFG), `kernel/src/shell/mod.rs`.

**Test:** scenariul `log`: pe mașina q35 apar puntea gazdă (8086:29c0), controlerul AHCI (clasa 01:06) și placa de rețea
implicită; scenariu cu `-device qemu-xhci` → apare clasa 0c:03:30.

**Riscuri:** BAR-uri pe 64 de biți (două registre); dimensiunea BAR-ului se află scriind 0xFFFFFFFF — doar cu decodarea oprită.

**Surse:** PCI Local Bus Specification (descriere publică), PCI Express Base Spec (ECAM), specificația ACPI (MCFG); OSDev Wiki „PCI” (doar ideea).
