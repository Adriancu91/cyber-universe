# P6-53 — F6a: browser text (C-68)

## Scop
O comandă care descarcă o pagină prin HTTPS și o arată ca text: titluri, paragrafe, liste, legături numerotate.

## Pași
1. Analizor HTML tolerant (scris de noi): etichete, entități, ignoră script/style.
2. Paginare pe ecran, `deschide N` pentru legătura N.

## Fișiere
`user/src/...`, README.

## Test
QEMU cu server local: o pagină de test se afișează cu titlu, liste și legături.

## Riscuri
Pagini moderne (JavaScript) nu se văd — e doar treapta (a).

## Surse
Specificația HTML (WHATWG), doar ca referință publică.
