# P4-05 — Ferestre pentru programe (apeluri de sistem, memorie partajată)

**Scop:** un program din `user/` își deschide fereastra, desenează în ea și primește tastele și clicurile.

**Pași**
1. Apeluri: `window_create(lățime, înălțime, titlu)`, `window_present(zonă)`, `event_wait()`.
2. Bufferul ferestrei mapat și în spațiul de adrese al programului (aceleași cadre fizice, drepturi de scriere).
3. Biblioteca `user/` primește un mic `Canvas` pentru programe.
4. La ieșirea programului fereastra se închide singură.

**Fișiere:** `kernel/src/syscall/ui.rs`, `kernel/src/ui/server.rs`, `user/src/gfx.rs`, `user/src/bin/demo.rs`.

**Test:** scenariu `appwindow`: `run demo` deschide o fereastră cu un dreptunghi colorat; captură → pixelii ferestrei corecți; programul primește o tastă trimisă de QEMU și iese.

**Riscuri:** cadrele partajate trebuie eliberate o singură dată (nucleul le deține, procesul doar le mapează).

**Surse:** design propriu.
