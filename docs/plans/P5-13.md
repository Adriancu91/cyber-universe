# P5-13 — Criptografie 4: semnături și certificate

**Scop:** nucleul TLS poate verifica lanțul de certificate al unui server: citește certificatele X.509 și verifică
semnăturile RSA (PKCS#1 v1.5 și PSS) și ECDSA P-256.

**Pași**
1. Cititor DER minimal (TLV) și X.509: emitent, subiect, valabilitate, cheia publică, extensiile de bază (numele DNS
   alternative, „basic constraints”), algoritmul și semnătura.
2. Numere mari pentru RSA (exponențiere modulară Montgomery, chei 2048–4096 de biți); verificare PKCS#1 v1.5 și PSS (SHA-256/384).
3. ECDSA P-256: aritmetica curbei (coordonate Jacobi), verificarea semnăturii.

**Fișiere:** `crypto/src/{der.rs,x509.rs,bignum.rs,rsa.rs,p256.rs}`, test în scenariul `crypto`.

**Test:** vectori NIST (FIPS 186 / CAVP) pentru ECDSA P-256 și RSA; un certificat generat la test cu `openssl` (rădăcină + server)
se verifică, iar unul cu semnătura stricată e refuzat.

**Riscuri:** e cea mai mare parte; se poate împărți din nou (RSA / ECDSA / X.509) dacă depășește o sesiune.

**Surse:** RFC 5280, RFC 8017 (PKCS#1), FIPS 186-5, SEC 1, X.690 (DER).
