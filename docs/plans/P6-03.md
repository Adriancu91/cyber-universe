# P6-03 — Parser și generator JSON propriu (crate `json/`)

**Scop:** programele din OS citesc și scriu JSON (API-ul Claude, API-ul GitHub).

**Pași**
1. Crate `json/` (no_std + alloc, fără dependențe): `Value` (null, bool, număr, text, listă, obiect cu ordinea păstrată),
   `parse(&str)`, `to_string()`; texte cu `\uXXXX` și perechi surogat (diacritice, emoji), numere întregi și zecimale.
2. Limite: adâncime maximă 64, mărime maximă dată de apelant; erori cu poziția.

**Fișiere:** `json/`, CI (`cd json && cargo test --release`).

**Test:** teste pe gazdă cu exemplele din RFC 8259 și cazuri greșite (virgulă în plus, ghilimea lipsă, adâncime prea mare);
verificare încrucișată cu Python `json` pe ~200 de documente generate.

**Surse:** RFC 8259 (JSON), ECMA-404.
