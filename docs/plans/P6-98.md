# P6-98 — C-148 pachetul 1: jurnalul mai rar pe stick (etapa 1) + măsurătorile etapei 0 (C-147) → `os-309`

**Scop:** la `os-308` (ciclul automat, 19 nov) Kronos #513 pe placă: 10,99 simboluri/s cu driverul, din care ~74 ms pe
simbol „jurnal”. Cyber-GPU (sesiunea 118, `os-308_ecoul-jurnalului.md`) a arătat cauza: fiecare rând de rutină ținut
trece totuși prin `info!` (port serial + ecran, ~4 ms/rând) și stick-ul e sincronizat la fiecare simbol. Adrian
(C-148, 19 nov 22:33): rândurile de rutină nu se mai afișează, se scriu pe stick la cel mult 1–2 secunde sau la 16
simboluri și la final; un rând important nu se pierde niciodată; plus măsurătorile etapei 0 de la Cyber-GPU (C-147
punctul 1, commit `02bbc36`) → Release `os-309`, testat de centrul de comandă prin ciclul automat.
