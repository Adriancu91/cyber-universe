# P6-238 — PREDARE Cyber-GPU P2zw (`8125211`) punctul 3: proba atenției pe circuitele speciale și la treapta 64 KiB

**Scop:** în os-462, `attn_back_tile_tc16` a câștigat în pasul mixt #513 6,7 ms, nu 2,2–4,0 cât prezisese Cyber-GPU. Cauza
(DEDUS de ei): proba `--atentie-tc` lansează programul la cea mai mică treaptă a memoriei comune (16 KiB → 1 bloc pe unitate),
iar pasul îl rulează la 64 KiB (3–4 blocuri). Ca predicțiile să fie bune, proba trebuie să măsoare și ce rulează în pas.

**Pași:**
1. Opțiune nouă, oprită implicit: `test-placa … --atentie-tc [--atentie-tc16-v4] [--atentie-tc0 [--atentie-tc0-v4]] --atentie-tc-64k`
   (doar imediat după una din ele); `gpu_tur::ATTN_TC_64K_IN_CYCLE`; build-ul de test: `gpu atentie-tc-sim on 64k` / `v4-64k`.
2. `gpu_i14.rs`: `AttnTcProg::launch_bytes(…, step)` — `Some(64 KiB)` = QMD cu `to_bytes_with_sm_config` (aceleași câmpuri ca
   `--treapta-pas`, pe placă din os-431). Pe fiecare set mic: după programele de azi, fiecare program care a rulat (v4 / v4pf doar
   unde `fits`) încă o dată la 64 KiB, dqkv + garda umplute cu NaN, cuvintele comparate cu rularea de azi a aceluiași program.
   La `atentie-513-b4` (doar placa): benzile umplute cu NaN, 5 lansări, mediana, benzile comparate cu cele de azi.
3. Rânduri: `kt atentie-tc@64k set N …`, verdictul `atentie-tc@64k (…): TRECE / NU TRECE` (trece = aceiași biți peste tot,
   gărzi neatinse), timpii pe lansare și × 12 pe pas; jurnal: `kt atentie-tc@64k seturi cu aceiasi biti`,
   `kt atentie-tc@64k mare timp <program> (ns)`.
4. Scenariul `kronos-gpu-atentie-tc-v4` pornește acum `v4-64k` (fără scenariu nou: CI e aproape de limita de 60 min pe parte).

**Fișiere:** `kernel/src/drivers/{gpu_i14,gpu_tur}.rs`, `kernel/src/shell/{ciclu,mod}.rs`, `kernel/src/drivers/README.md`,
`tests/scenarios.txt`.

**Test:** `tools/test.sh kronos-gpu-atentie-tc-v4 ghpush boot` (`ghpush` rulează `ciclu::self_test` cu formele noi).

**Riscuri:** nimic nou pentru placă (aceleași programe, câmpurile treptei deja folosite în pas). Dacă la 64 KiB biții diferă,
pasul mixt cu tc16 / v4 trebuie reverificat (dar os-462 a dat deja aceleași numere ca oracolul).
