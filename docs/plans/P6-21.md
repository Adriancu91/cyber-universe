# P6-21 — `gpu gfw` și `gpu vbios`, doar citire (comanda C-19)

## Scop
- Fixarea Cyber-GPU mutată de pe `41e44ba` pe `dac2e32` (ultimul commit „Stare: sesiunea 5” de pe `g0-g2-fundatie`; în cyber-gpu nu
  există `main`; ghidul lor `integration/cyber-universe/UTILIZARE.md` promite doar adăugări).
- `gpu gfw` (pasul I2 din cyber-gpu): așteaptă ca firmware-ul plăcii să termine pornirea (max 4 s), arată rundele, timpul, ultimele valori.
- `gpu vbios` (pasul I3): lista imaginilor din fereastra PROM (offset, tip, mărime), tabela BIT și jetonul 0x70, numărul de citiri.
- Ambele **doar citire**: numărul de scrieri cerute de bibliotecă (toate refuzate) e afișat, ca la `gpu identifica`.
- Release nou pentru fereastra de pe workstation. os-187 rămâne punctul de revenire.

## Pași
1. `kernel/Cargo.toml`, `user/Cargo.toml`: `rev = "dac2e32"`; `CYBER_GPU_REV` în `drivers/gpu.rs`.
2. `drivers/gpu.rs`: `ReadOnlyBar0Window` = `gpu_core::hal::Mmio` cu lungimea 4 MiB (`INIT_WINDOW`); la fiecare citire mapează pagina
   necesară (fără WRITABLE, necache-abilă) în fereastra existentă; scrierile se refuză și se numără. Ceas = TSC (`time::since_boot_us`).
3. `gpu_gfw()` / `gpu_vbios()`: placa trebuie recunoscută de `probe_config` (GA104), cu Memory Space pornit de firmware (nu-l pornim noi).
4. `--sim` (doar build de test): același cod pe `gpu-sim` (GFW gata după câteva runde; lanțul ROM sintetic `ga10x_like_chain_with_fwsec`).
5. Shell: `gpu gfw [--sim]`, `gpu vbios [--sim]`; `gpu plan` cu pașii noi.

## Fișiere
`kernel/Cargo.toml`, `user/Cargo.toml`, `Cargo.lock`-uri, `kernel/src/drivers/gpu.rs`, `kernel/src/shell/mod.rs`, `tools/test.sh`,
`docs/TASKS.md`, `docs/STATE.md`.

## Test
- Scenariul `gpu-sim`: `gpu gfw --sim` → „GFW gata (0xff)”, „0 scrieri”; `gpu vbios --sim` → PCI-AT, EFI, FWSEC, „BIT … 0x70”, „complet: da”, „0 scrieri”.
- Scenariul `gpu` (QEMU, fără NVIDIA): `gpu gfw` / `gpu vbios` → „nicio placa NVIDIA”.
- Toate scenariile vechi; CI verde → Release.

## Riscuri
- O citire în fereastra PROM fără „umbrire” poate întoarce gunoi: biblioteca se oprește dacă primul cuvânt nu e semnătură (nu scrie nimic).
- Remaparea paginii la fiecare schimbare: ~260 de remapări pentru tot VBIOS-ul, sub limita de 2 s.
