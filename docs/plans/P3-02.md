# P3-02 — Driver AHCI (discuri SATA), doar citire

**Scop:** citirea sectoarelor de pe un disc SATA real; `/disk` vine de pe disc, nu din memorie.

**Pași**
1. Găsește controlerul prin PCI (clasa 01:06:01), mapează ABAR (BAR5) necache-uit, activează bus master.
2. Inițializare HBA: preia controlul de la BIOS (BOHC), pornește porturile cu dispozitiv prezent.
3. Structuri pe port: listă de comenzi, FIS primite, tabel de comandă cu PRDT (cadre fizice din alocator).
4. Comanda ATA `READ DMA EXT` (0x25) prin polling; mai târziu cu întreruperi.
5. `AhciDisk` implementează `BlockDevice`; `fs` montează prima partiție FAT32 găsită la `/disk`.

**Fișiere:** `kernel/src/drivers/ahci.rs`, `kernel/src/drivers/README.md`, `kernel/src/fs/mod.rs`, `tools/qemu-common.sh` (discul de test atașat SATA).

**Test:** scenariul `log` rulat cu `disk.img` atașat ca disc SATA (`-drive if=none,id=d,file=...,format=raw -device ide-hd,drive=d,bus=ide.0`
pe controlerul AHCI din q35): `test: FAT32 OK` trece citind prin AHCI.

**Riscuri:** memoria DMA trebuie să fie fizic contiguă și sub 4 GiB dacă HBA nu suportă 64 de biți (bitul S64A).

**Surse:** Serial ATA AHCI 1.3.1 Specification (Intel, publică); ATA/ATAPI Command Set (ACS) — doar documentație.
