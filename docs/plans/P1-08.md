# P1-08 — Tabelele ACPI

**Scop:** nucleul găsește informațiile despre procesoare și controlere de întreruperi.

**Pași**
1. Cerere Limine `RsdpRequest` → adresa RSDP.
2. `kernel/src/acpi/`: validează sumele de control; RSDT/XSDT → lista tabelelor.
3. Parsează MADT: adresa APIC local, procesoarele (APIC ID), I/O APIC, suprascrieri de IRQ (ISO).
4. Afișează în jurnal lista tabelelor găsite (semnături: `FACP`, `APIC`, `HPET`, `MCFG`...).

**Fișiere:** `kernel/src/acpi/{mod,tables,madt}.rs`.

**Test:** în QEMU q35 se găsesc cel puțin `FACP` și `APIC`; cu `-smp 2` MADT raportează 2 procesoare.

**Riscuri:** tabelele pot fi în memorie nemapată → mapează la nevoie prin HHDM/P1-06.
Interpretorul AML (bytecode ACPI) NU intră aici — e o sarcină mare, separată, pentru Faza 3.

**Surse:** ACPI Specification 6.5 (cap. 5); OSDev Wiki „RSDP”, „MADT”.
