# P1-07 — Heap-ul nucleului

**Scop:** în nucleu se pot folosi `Box`, `Vec`, `String` din crate-ul `alloc`.

**Pași**
1. Zonă virtuală dedicată heap-ului (ex. `0xffff_9000_0000_0000`), mărime inițială 1 MiB, extinsă la cerere.
2. Alocator propriu, simplu: listă de blocuri libere (linked list) cu unire a blocurilor vecine.
3. `#[global_allocator]` și handler pentru eșec de alocare (mesaj clar + panică).
4. Statistici: memorie heap folosită/liberă.

**Fișiere:** `kernel/src/mem/heap.rs`, `kernel/src/main.rs` (`extern crate alloc`).

**Test:** `Vec` cu 1.000.000 de `u64`, apoi eliberat; 10.000 de `Box` mici alocate/eliberate în ordine amestecată; memoria folosită revine aproape de zero.

**Riscuri:** fragmentare; acceptabilă acum. Un alocator mai bun (slab) poate fi o sarcină ulterioară.

**Surse:** OSDev Wiki „Memory Allocation”; documentația Rust `GlobalAlloc`.
