# P6-14 — USB: dispozitive în spatele hub-urilor (comanda C-13, punctul 2)

**Scop:** pe workstation stick-ul ADATA nu apare, pentru că e în spatele unui hub (`0bda:0411` USB 3, `0bda:5411` USB 2).
Driverul xHCI enumeră acum doar porturile rădăcină.

**Pași**
1. La un dispozitiv de clasa 09 (hub): Configure Endpoint cu bitul Hub din contextul slotului, numărul de porturi și (pentru USB 2 de
   mare viteză) TT; citește descriptorul de hub (USB 2.0 cap. 11.23 / USB 3.x cap. 10.15).
2. Pentru fiecare port: Set Port Feature PORT_POWER, așteaptă, Get Port Status; la conexiune: Set Port Feature PORT_RESET, așteaptă
   C_PORT_RESET, viteza din starea portului.
3. Enable Slot + Address Device pentru dispozitivul din spate, cu **Route String** (4 biți pe nivel), Root Hub Port Number al hub-ului,
   iar pentru dispozitivele lente/full-speed în spatele unui hub de mare viteză: TT Hub Slot ID și TT Port Number.
4. Apoi enumerarea obișnuită (HID, Mass Storage). Fiecare pas în `log usb`. Release separat de P6-13 (D-013).

**Fișiere:** `kernel/src/drivers/usb/` (xhci, enumerarea), `docs/USB.md`, `tests/scenarios.txt`.

**Test:** QEMU `-device usb-hub,bus=xhci.0,port=1` cu `usb-storage` și `usb-kbd` pe porturile hub-ului → apar în `lsusb`, `/usb` montat.

**Riscuri:** hub-urile USB 3 au două jumătăți (USB 3 și USB 2) — dispozitivul apare pe una singură; temporizările de reset.

**Surse:** USB 2.0 Specification cap. 11 (hub), USB 3.2 cap. 10 (hub SuperSpeed), xHCI Specification 1.2 (Slot Context, Route String, TT).
