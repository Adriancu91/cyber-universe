# P6-234 — PREDARE Cyber-GPU P2zs (`f6ce737`): `attn_back_tile0_tc` lângă dS-ul F32 (proba întâi)

**Scop:** `attn_back_tile0_3` (dS al atenției) e cel mai încet program pe FLOP (os-431: 5 182 µs pe pasul #513). Cyber-GPU a
scris `attn_back_tile0_tc`: doar produsul dP = dO·Vᵀ pe circuitele speciale (f16 → f32), restul F32 în aceeași ordine.
Înainte să intre în pasul mixt, trebuie văzut pe placă „vechi lângă nou”: aceleași P / dO / V, abaterea față de dS-ul F32,
nicio poziție nescrisă, timpul.

**Pași:**
1. Fără schimbare de dependență (cyber-gpu e deja `f6ce737`).
2. Opțiune nouă, oprită implicit: `test-placa … --atentie-tc [--atentie-tc16-v4] --atentie-tc0` (doar imediat după
   `--atentie-tc` sau `--atentie-tc16-v4`); `gpu_tur::ATTN_TC0_IN_CYCLE`; build-ul de test: `gpu atentie-tc-sim on tc0`.
3. `gpu_i14.rs`: programul verificat SHA-256, încărcat după tc / tc16. Pe fiecare set mic, după programele dQ / dK / dV:
   dS-ul F32 al lanțului nou citit, zona dS + garda umplute cu NaN, o lansare `attn_back_tile0_tc` (cbuf 0x800, argumentele
   la 0x700, grila `[⌈T/64⌉, H, B]`), dS înapoi. Pe `atentie-513-b4` (doar placa): rândurile T − 1 ale textelor din benzi,
   toate capetele, citite F32, umplute cu NaN, 5 lansări, citite înapoi.
4. Rânduri: `kt atentie-tc0 set N …` (timp lângă dS F32, abaterea sub diagonală, NaN sub diagonală, zerourile de deasupra,
   garda, cuvintele exacte față de `gpu_compute::attn_tc::back0_model`); verdictul `atentie-tc0 (vechi langa nou, …): TRECE /
   NU TRECE` (trece = 5 / 5 seturi cu abaterea ≤ 1e-3, 0 NaN sub diagonală, garda neatinsă; la set mare la fel + finite);
   jurnal: `kt atentie-tc0 exacte (model)`, `… abatere (x1e6)`, `… garda (NaN sub diagonala)`, `… timp (ns)`, `… timp dS F32 (ns)`.
   Zerourile de deasupra și „exacte (model)” sunt doar afișate (modelul sumatorului e ipoteză, os-335).
5. Înlocuitorul `gpu_sim::cmdproc::attn_back_tile0_tc_on_cpu` înregistrat în simulator; scenariul `kronos-gpu-atentie-tc0`.

**Fișiere:** `kernel/src/drivers/{gpu_i14,gpu_i10,gpu_tur}.rs`, `kernel/src/shell/{ciclu,mod}.rs`, `kernel/src/drivers/README.md`,
`tests/scenarios.txt`, `tests/durate-ci.txt`.

**Test:** `tools/test.sh kronos-gpu-atentie-tc0 kronos-gpu-atentie-tc ghpush boot`.

**Riscuri:** un program nou pe placă (56 registre, 33 024 B partajați, o barieră). Dacă abaterea e mult peste 3e-4 sau rămân
NaN, programul nu intră în pasul mixt (pasul 2 al notei, `--atentie0-tc`, rămâne pentru după rezultat).
