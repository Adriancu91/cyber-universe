# P6-49 — F2: remote text direct din OS (C-68)

## Scop
Ecranul text al shell-ului și tastatura, prin rețea, fără Windows la mijloc: merge în mașina virtuală și pe workstation.

## Pași
1. Un serviciu TCP în OS (port fix, ex. 2323) care trimite ce scrie consola și primește taste.
2. Autentificare: o cheie lungă din fișierul `remote.cheie` de pe stick/discul mașinii (nu în repo); fără cheie serviciul nu pornește. Cheia se verifică în timp constant; după 3 greșeli, pauză.
3. Doar comenzile din lista albă a shell-ului (aceeași listă ca bucla automată); nimic cu placa video.
4. Criptare: întâi doar pe legătura locală / tunel (mașina virtuală, `hostfwd` pe 127.0.0.1); apoi TLS (biblioteca `tls/` există).
5. Un mic client (`tools/remote.py`) pentru test.

## Fișiere
`kernel/src/net/...` sau program în `user/`, `tools/remote.py`, `docs/MASINA_VIRTUALA.md`.

## Test
QEMU cu `hostfwd`: clientul se conectează, cheie greșită refuzată, cheie bună → `help` și `uptime` primesc răspuns; o comandă din afara listei e refuzată.

## Riscuri
Siguranța (cineva din rețea). Implicit oprit; pornit doar cu cheia pe disc.

## Surse
RFC 854 (Telnet) doar ca idee de protocol simplu; documentația QEMU `hostfwd`.
