# P5-05 — Rețea pentru programe (socket-uri) și aplicația „Rețea”

**Scop:** programele din `user/` folosesc rețeaua: UDP, TCP, rezolvare de nume; o aplicație arată starea rețelei.

**Pași**
1. Apeluri de sistem: `socket`, `connect`, `send`, `recv`, `close`, `resolve` (descriptorii merg prin același tabel ca fișierele).
2. Biblioteca `user/`: `TcpStream`, `UdpSocket` simple, fără heap.
3. Aplicația grafică `network`: adresă, rută, DNS, pachete, ping la o adresă scrisă de utilizator.

**Fișiere:** `kernel/src/syscall/net.rs`, `user/src/net.rs`, `user/src/bin/network.rs`.

**Test:** scenariu `appnet`: un program descarcă pagina serverului de test (ca la P5-04) și o scrie pe serial.

**Surse:** design propriu (ideile socket-urilor BSD, fără cod).

**Notă la final (2026-10-20):** în loc de `socket` + `connect` separate: `tcp_connect` și `udp_open` dau direct un
descriptor; `send`/`recv` pentru TCP sunt `write`/`read` obișnuite; UDP are `udp_send`/`udp_recv` (cu adresa). În plus
față de plan: `net_info`, `ping` (pentru aplicația „Rețea”) și programele `fetch` și `udp`. Testul `appnet` pornește
serverul web de test și un server UDP „ecou” (`tools/before-appnet.sh`), rulează `fetch` (pagină găsită + 404) și `udp`,
apoi aplicația „Rețea” cu taste simulate (4 ping-uri, captură).
