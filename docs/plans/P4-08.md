# P4-08 — Manager de module (modmgr)

**Scop:** module care se instalează, pornesc, opresc și dezinstalează — baza „totul e modul” din ARCHITECTURE.md.

**Pași**
1. Formatul pachetului: arhivă `.cum` (tar ustar) cu `module.toml` (nume, versiune, descriere, dependențe, program de pornire) și fișierele lui.
2. Instalare în `/modules/<nume>/` pe disc (FAT32, P4-07); evidența în `/modules/index`.
3. Comenzi shell: `mod list`, `mod install <fișier>`, `mod start|stop <nume>`, `mod remove <nume>`.
4. Verificarea dependențelor la instalare și la ștergere.

**Fișiere:** `kernel/src/modmgr/mod.rs` (sau program separat), `tools/mkmodule.sh`, `docs/specs/MODULE.md`.

**Test:** scenariu `modules`: un modul de test construit la build se instalează de pe discul de test, pornește (scrie un mesaj), se oprește și se șterge; directorul lui dispare.

**Riscuri:** cititorul TOML: doar un subset mic (chei simple, șiruri, liste) scris de noi.

**Surse:** design propriu.
