# P6-90 — `analiza` folosește faptele din `gpu tur --trezire` (laptopul, Memory Space oprit)

**Scop:** testul din 13 nov pe laptopul ASUS cu `os-301` (`rezultate/2026-11-13-laptop-asus-os301/REZULTAT.md` din hub, „De
îmbunătățit (pentru echipa OS)” pct. 1): `analiza` arăta „placa NVIDIA: 0 fapte | cip – | VRAM – | GFW –”, deși în aceeași pornire
`gpu tur --trezire` citise 45 de fapte. Pe laptop firmware-ul lasă Memory Space oprit, iar `analiza` e doar citire (nu trezește
placa). Face parte din C-117 (analizatorul UHL, „da” de la Adrian); nu adaugă nicio scriere.

**Pași**
1. `drivers/gpu_tur.rs`: ultimul `gpu tur --trezire` reușit (cu fapte) din pornirea curentă se ține minte (adresa PCI, ora, rândurile);
   la fel turul treaz al modelului laptopului din `--sim`.
2. `hw/uhl.rs`: `pick_tour` — dacă turul simplu al analizei n-are fapte și există un tur treaz al ACELEIAȘI plăci, inventarul ia faptele
   lui; proprietăți noi `facts_source` (de unde vin faptele și ora) și `analysis_tour_result` (ce a spus turul simplu); `writes_to_board`
   = „0 în registrele plăcii; 2 în registrul Command PCI la gpu tur --trezire (repus)”; în `report.txt` rândul „faptele plăcii: din …”.
3. `shell/analiza.rs`: folosește `pick_tour` și spune pe ecran de unde vin faptele.
4. Test: verificarea `check_pick_tour` în scenariul `analiza-gpu` (Memory Space oprit + tur treaz → fapte marcate; altă placă / fără tur
   treaz / tur simplu cu fapte → turul simplu rămâne; JSON + raport).

**Fișiere:** `kernel/src/drivers/gpu_tur.rs`, `kernel/src/hw/uhl.rs`, `kernel/src/shell/analiza.rs`, `tests/scenarios.txt`.

**Test:** `tools/test.sh analiza-gpu analiza gpu-ga106 gpu-tur`, apoi toată suita. Pe laptop: `gpu tur --trezire` (DA), apoi `analiza`
→ rândul „placa NVIDIA: NVIDIA GA106 | 45 fapte | cip GA106 | VRAM 6144 MiB …” și „faptele placii: din gpu tur --trezire …”.

**Riscuri:** niciunul pe placă (zero scrieri noi; `analiza` rămâne doar citire). Faptele pot fi cu câteva minute mai vechi decât
analiza — de aceea ora turului e în inventar.

**Surse:** hub `rezultate/2026-11-13-laptop-asus-os301/REZULTAT.md`; C-117; C-116.
