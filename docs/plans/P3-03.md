# P3-03 — Driver NVMe, doar citire

**Scop:** citirea de pe SSD-uri NVMe (laptopurile moderne, inclusiv ThinkPad L15 Gen 2).

**Pași**
1. Găsește controlerul prin PCI (clasa 01:08:02), mapează BAR0.
2. Reset controller, cozi de administrare (Admin SQ/CQ), `Identify Controller` și `Identify Namespace`.
3. O pereche de cozi I/O; comanda `Read`; așteptare prin polling pe coada de terminare (bitul de fază).
4. `NvmeDisk` implementează `BlockDevice`.

**Fișiere:** `kernel/src/drivers/nvme.rs`, README.

**Test:** scenariu `nvme`: QEMU cu `-drive file=disk.img,if=none,id=n -device nvme,serial=cu1,drive=n` → `/disk` montat prin NVMe, `test: FAT32 OK`.

**Riscuri:** mărimea paginii controlerului (CAP.MPSMIN); PRP pentru transferuri peste 2 pagini → limitează la 8 KiB per comandă la început.

**Surse:** NVM Express Base Specification (publică) — doar documentație.
