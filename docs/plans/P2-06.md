# P2-06 — Încărcarea programelor ELF

**Scop:** nucleul poate porni un program dintr-un fișier ELF64 static (construit separat în Rust, `no_std`).

**Pași**
1. Folder `user/` cu un crate pentru programe și o mică bibliotecă de apeluri de sistem (`user/lib`).
2. `tools/build.sh` construiește programele și le pune în ISO ca module Limine (până există ramfs: P2-07).
3. Încărcător ELF: verifică antetul (ELF64, x86_64, executabil), mapează segmentele `PT_LOAD` cu drepturile cerute,
   zero pentru `.bss`, stivă utilizator, salt la punctul de intrare.
4. Proces = spațiu de adrese + fir; `exit` eliberează tot.

**Fișiere:** `kernel/src/proc/elf.rs`, `kernel/src/proc/mod.rs`, `user/`, `tools/build.sh`, `boot/limine/limine.conf`.

**Test:** scenariu `elf`: programul `hello` scrie „hello din ELF” și iese cu 0; un fișier ELF stricat (antet greșit)
e refuzat cu mesaj clar; memoria liberă revine după ieșire.

**Riscuri:** segmente nealiniate la pagină; un ELF rău intenționat cu dimensiuni uriașe → limite verificate înainte de alocare.

**Surse:** specificația ELF (System V gABI) și suplimentul AMD64 psABI; specificația Limine (Module Request).
