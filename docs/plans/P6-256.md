# P6-256 — Verificarea rândurilor `test-placa` pe gazdă (`tools/verifica-rand.py`)

## Scop
Înainte ca un rând să ajungă în `auto\teste.txt` pe stick, oricine (sesiunea OS, Cyber-GPU, centrul de comandă) poate afla
pe loc, fără QEMU și fără placă, dacă lista automată îl primește — cu **exact** codul din `kernel/src/shell/ciclu.rs` —
și, dacă nu, motivul (același text ca în raportul OS-ului, `board_refusal_hint`). Lecția: rândul P2zzl refuzat la
27 nov 13:28 (`--mm-tc-v5` fără `--mm-tc-v4` înainte) a costat un loc pe placă.

## Pași
1. Scriptul copiază din sursele nucleului: constantele opțiunilor (`pub const …: &str`), `BOARD_OPTIONS`,
   `TRAIN_513_BATCH_MAX`, funcțiile `board_command`, `board_command_form`, `board_refusal_hint` și numele I9 din
   `gpu_golden::i9_option`; le compilează cu `rustc` într-un program mic de gazdă și îi dă rândurile.
2. Moduri: rânduri pe linia de comandă; `--din <fișier.md>` = toate rândurile `test-placa …` dintre apostroafe
   (sar peste cele prescurtate cu `…`, `[ ]`, `< >`, `*`); `--ultima-sesiune` = doar prima intrare din „Ultima sesiune”.
3. Ieșirea: `PRIMIT` / `REFUZAT` + motivul; cod 0 = toate primite, 1 = cel puțin unul refuzat, 2 = unealta n-a putut rula
   (de ex. codul din `ciclu.rs` și-a schimbat forma — atunci se repară scriptul, nu se ghicește).
4. În CI (partea `stick`): rândul greșit de la 13:28 trebuie refuzat, forma lui corectă primită, iar rândurile ultimei
   sesiuni din STATE.md primite.

## Fișiere
`tools/verifica-rand.py` (nou), `.github/workflows/ci.yml`, `docs/TESTING.md` (cum se folosește).

## Test
- Local: rândul de la 13:28 → `REFUZAT … --mm-tc-v5 nu poate sta dupa --mm-tc`; rândul corectat → `PRIMIT`; un rând cu
  `--viteza-1800` fără `--mm-tc-dxdw` → motivul deciziei lui Adrian; rândul os-496 din STATE.md → `PRIMIT`.
- CI: pasul nou din partea `stick`.

## Riscuri
- Codul copiat depinde de forma lui `ciclu.rs` (funcții la nivelul de sus, constante pe un rând). Dacă se schimbă,
  scriptul se oprește cu cod 2 și CI-ul arată ce lipsește.
- Nu înlocuiește verificarea din nucleu: OS-ul tot refuză singur un rând greșit; unealta doar spune mai devreme.
