# P0-02 — Configurarea Rust pentru nucleu

**Scop:** proiect Rust `no_std` care se compilează pentru `x86_64-unknown-none` cu nightly.

**Pași**
1. `kernel/rust-toolchain.toml`: `channel = "nightly"`, `components = ["rust-src"]`, `targets = ["x86_64-unknown-none"]`.
2. `kernel/Cargo.toml`: pachet `cyber_kernel`, ediția 2024, `panic = "abort"` pe `dev` și `release`.
3. `kernel/.cargo/config.toml`: `target = "x86_64-unknown-none"`, rustflags `relocation-model=static`, `code-model=kernel`.
4. `src/main.rs` minim: `#![no_std] #![no_main]`, `#[panic_handler]` cu buclă infinită.

**Fișiere:** `kernel/rust-toolchain.toml`, `kernel/Cargo.toml`, `kernel/.cargo/config.toml`, `kernel/src/main.rs`.

**Test:** `cd kernel && cargo build` reușește fără avertismente.

**Riscuri**
- Eroare „can't find crate for `core`”: lipsește ținta sau `rust-src`; rulează `rustup target add x86_64-unknown-none --toolchain nightly`.
- Ediția 2024 cere `#[unsafe(no_mangle)]` în loc de `#[no_mangle]`.

**Surse:** prototip `docs/research/prototip-p0/`, documentația Rust despre `no_std` și ținta `x86_64-unknown-none`.
