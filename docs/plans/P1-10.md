# P1-10 — Tastatura PS/2

**Scop:** tastele apăsate apar pe ecran și pe serial.

**Pași**
1. Inițializare controler 8042 (dezactivare/activare porturi, test, configurare).
2. IRQ 1 rutat prin I/O APIC (ține cont de suprascrierile din MADT) la un vector propriu.
3. Decodare scancode set 1 → taste; Shift, Caps Lock; aranjament US (aranjament românesc: sarcină ulterioară).
4. Coadă circulară de taste; consola le afișează.

**Fișiere:** `kernel/src/drivers/ps2.rs`, `kernel/src/drivers/keyboard.rs`.

**Test:** `test.sh` trimite prin monitorul QEMU (`-monitor unix:...`) comenzile `sendkey h`, `sendkey i`, `sendkey ret`;
nucleul scrie pe serial `KEY: h`, `KEY: i`, `KEY: Enter`.

**Riscuri:** pe ThinkPad tastatura internă poate să nu fie PS/2 (vezi studiu §5) — normal; driverul USB vine în Faza 3.

**Surse:** OSDev Wiki „8042 PS/2 Controller”, „PS/2 Keyboard”.
