# Planuri de lucru pe sarcini

Fiecare sarcină din `docs/TASKS.md` are aici un fișier `<ID>.md` cu:
- **Scop** — ce trebuie să existe la final;
- **Pași** — ordinea recomandată;
- **Fișiere** — ce se creează sau modifică;
- **Test** — cum se dovedește că e gata (automat);
- **Riscuri** — unde se blochează de obicei și ce să încerci;
- **Surse** — de unde se studiază (vezi și `CLEAN_ROOM.md`).

Reguli:
- Planul e un ghid, nu o lege. Dacă în timpul lucrului descoperi o cale mai bună, actualizează planul în același commit.
- Când adaugi o sarcină nouă în coadă, creezi și planul ei aici (același format).
- Prototipul verificat din `docs/research/prototip-p0/` e referință pentru Faza 0.
- Studiul de fond: `docs/research/STUDIU-P0-P1.md`.
