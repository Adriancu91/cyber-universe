# P6-101 — C-152 punctul 1: resetul plăcii din interior (FLR) în ciclul automat

**Scop:** coborârea plăcii în starea de pornire fără Windows, ca ciclul să poată rula mai multe teste la rând
(Adrian, „Da” treapta 1, 19 nov 23:37; DECIZII 23:37 punctul 1).

**Dependență:** nota Cyber-GPU pentru C-151 punctul 3 (pașii exacți și ce înseamnă fiecare rezultat). Până atunci
sarcina nu începe.

**Pași** (după notă): comanda de reset: Bus Master oprit → configurația PCI salvată → FLR → 100 ms → configurația
rescrisă → așteptarea pornirii plăcii (doar citiri) → WPR2 recitit. Proba, într-un Release separat: lanțul obișnuit →
WPR2 citit (așteptat ridicat) → resetul → WPR2 citit (așteptat 0) → lanțul a doua oară în aceeași pornire. WPR2 tot
ridicat sau placa nu răspunde: oprire curată, rând clar în raport, repornire în Windows — fără a doua încercare.

**Fișiere:** `kernel/src/drivers/gpu_rec.rs`, `gpu_tur.rs`, ciclul (`ciclu-test`), `docs/BUCLA_AUTOMATA.md`.

**Test:** modelul `gpu-sim` „WPR2 ridicat → FLR → WPR2 coborât → lanțul trece a doua oară”; scenariu QEMU; CI verde.

**Riscuri:** singura unealtă cu risc pe placă; fallback = calea de azi (Windows).

**Surse:** hub C-151, C-152; cyber-gpu `docs/C-142_K513_VITEZA_FLR.md` §4; PCIe Base 4.0 §6.6.2 (FLR).
