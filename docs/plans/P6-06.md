# P6-06 — Uneltele lui Claude în OS (agent înăuntru)

**Scop:** Claude poate cere: citește fișier, listează dosar, scrie fișier, rulează comandă din shell.

**Pași**
1. Cererea către API declară uneltele (`tools`, JSON Schema); răspunsurile `tool_use` sunt executate de aplicație, rezultatul
   se trimite înapoi (`tool_result`), până când Claude răspunde cu text.
2. **Citire și listare:** fără confirmare. **Scriere și rulare:** o casetă pe ecran cu ce vrea să facă exact (calea și
   conținutul pe scurt / comanda) și butoanele „Da” / „Nu”; fără „Da” nu se face nimic.
3. Limite: mărimea fișierului citit, timpul comenzii, ieșirea comenzii tăiată la o mărime fixă.

**Fișiere:** `user/claude-app/`, `kernel/src/syscall/` (dacă e nevoie de rularea unei comenzi de shell dintr-un program).

**Test:** scenariul `claude-tools` cu serverul de test care cere pe rând fiecare unealtă; QEMU apasă „Nu” o dată și „Da” o dată;
se verifică pe disc ce s-a scris și ce nu.

**Riscuri:** siguranța — nicio unealtă nu ocolește confirmarea; căile se limitează la `/disk`, `/usb` și `/tmp` (fără `/bin`, `/etc`).

**Surse:** documentația publică Anthropic API (tool use).
