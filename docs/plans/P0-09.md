# P0-09 — Text pe ecran (framebuffer)

**Scop:** pe ecran apare „Cyber Universe OS” scris cu un font propriu.

**Pași**
1. Cerere `FramebufferRequest` (crate limine 0.5.0); citește `addr`, `width`, `height`, `pitch`, `bpp`.
2. `kernel/src/gfx/framebuffer.rs`: `put_pixel`, `fill_rect`, `clear(color)`.
3. Font bitmap 8×16 **desenat de noi** (caractere ASCII 32–126) în `kernel/src/gfx/font.rs`.
   Nu se copiază fonturi cu licență necunoscută; dacă se folosește un font existent, doar cu licență compatibilă MIT, notată în CLEAN_ROOM.
4. `gfx/console.rs`: cursor, scriere text, rând nou, derulare.
5. Fundal închis, titlu deschis la culoare, versiunea nucleului dedesubt.

**Fișiere:** `kernel/src/gfx/{mod,framebuffer,font,console}.rs`.

**Test:** în `test.sh` se trimite comanda QEMU monitor `screendump build/screen.ppm`; un script Python verifică
că imaginea nu e uniformă și că zona titlului conține pixeli de culoarea textului. Salvează un PNG în `tests/screens/`.

**Riscuri**
- `bpp` diferit de 32: tratează doar 32 acum, iar pentru alte valori afișează avertisment pe serial.
- Desenarea pixel cu pixel e lentă: OK pentru acum; optimizarea vine cu derularea.

**Surse:** OSDev Wiki „Drawing In a Linear Framebuffer”, „PC Screen Font”.
