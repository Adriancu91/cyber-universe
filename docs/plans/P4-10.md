# P4-10 — Aplicații de sistem: editor de text și setări

**Scop:** editor de text simplu (deschide, editează, salvează) și aplicația de setări (aranjament tastatură, rezoluție, oră).

**Pași**
1. Editor: buffer de text, cursor, selecție simplă, salvare pe FAT32.
2. Setări: fișier `/config/settings.toml`; aplicate la pornire.

**Fișiere:** `user/src/bin/editor.rs`, `user/src/bin/settings.rs`.

**Test:** scenariu cu taste trimise: editorul creează un fișier, îl salvează; nucleul îl citește și verifică conținutul.

**Surse:** design propriu.
