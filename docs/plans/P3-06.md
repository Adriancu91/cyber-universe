# P3-06 — Tastatură USB (HID, protocolul „boot”)

**Scop:** tastaturile USB merg (laptopurile au de obicei tastatură internă PS/2 emulată, dar tastaturile externe sunt USB).

**Pași**
1. Pe dispozitivele HID cu subclasa boot: `SET_PROTOCOL(boot)`, endpoint de întreruperi IN.
2. Rapoarte de 8 octeți → aceleași evenimente `Key` ca la PS/2 (aceeași coadă, același `wait_key`).
3. Repetare automată nu e necesară la început.

**Fișiere:** `kernel/src/drivers/usb/hid.rs`, `kernel/src/drivers/keyboard.rs`.

**Test:** scenariu `usb-kbd`: QEMU cu `-device usb-kbd`, taste trimise prin monitor (`sendkey` merge la ultima tastatură adăugată
sau prin QMP `input-send-event` cu `device`) → shell-ul primește comanda.

**Riscuri:** în QEMU, `sendkey` poate ajunge la PS/2 în loc de USB; verifică în jurnal sursa tastei.

**Surse:** USB Device Class Definition for HID 1.11 (anexa B, boot protocol); HID Usage Tables.
