# P6-32 — Stick construit în sesiune, livrat prin hub (comanda C-35)

## Scop
Cât timp GitHub Actions e oprit (fără minute, repo privat — B-005 pentru CI/Release), arhiva stick-ului se face în sesiunea din cloud,
după testele QEMU, și ajunge la Adrian prin hub-ul privat (`integrare/cyber-universe/stick/`). Fără plată, fără repo-uri publice (decizia din 28 oct 22:20).

## Pași
1. `tools/test.sh` — suita completă în QEMU (cele instabile cunoscute la `-smp 4` pe gazda cu 2 nuclee: reluate o dată).
2. `tools/build.sh --usb` + `tools/release-files.sh` — exact fișierele pe care le punea Release-ul (varianta B din `docs/USB.md` + imaginea întreagă).
3. `tools/stick-hub.sh <hub>` — verifică că în fișiere nu e modelul Kronos (`KGR1`) și nici firmware NVIDIA (`*.bin` GSP/`gsp_*`), face
   `stick-cyber-universe-os-<nr>.zip`, șterge arhiva veche din hub, scrie `VERSIUNE.txt` (număr, commit, ora UTC, SHA-256 al arhivei).
4. `README.md` în hub (ce e nou față de `os-197`), commit + push în hub.

## Numerotare
`os-<nr>` cu `nr` de la **1001** în sus (1001, 1002, ...): nu se poate confunda cu Release-urile CI (`os-197` și următoarele, numărul rulării CI).

## Fișiere
`tools/stick-hub.sh`, `docs/USB.md` (o notă), hub: `integrare/cyber-universe/stick/`.

## Test
Suita QEMU verde înainte; `sha256sum -c SHA256SUMS` în arhivă; dezarhivare de probă; suma din `VERSIUNE.txt` = suma arhivei.

## Riscuri
Arhiva e binară în git (~câțiva MB la fiecare versiune) — hub-ul crește; de aceea doar ultima arhivă în dosar (istoricul git o păstrează).
Fără CI, testele sunt doar cele din sesiune (QEMU), nu și cele cu internet.

## Surse
Comanda C-35 și decizia din 28 oct 22:20 din hub; `.github/workflows/ci.yml`, `tools/release-files.sh`.
