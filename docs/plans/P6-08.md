# P6-08 — Comanda „Actualizează”

**Scop:** `actualizeaza` (și butonul din Setări) descarcă ultima versiune și rescrie fișierele de pe stick.

**Pași**
1. Descarcă `VERSIUNE` și `SHA256SUMS` de la Release-ul `ultima` (P6-07), prin HTTPS (redirecționările GitHub către
   `objects.githubusercontent.com` trebuie urmate).
2. Dacă versiunea e alta: descarcă fiecare fișier în memorie, verifică SHA-256; abia când toate sunt bune, le scrie pe `/usb`
   (întâi `*.nou`, apoi înlocuire), cu golirea cache-ului discului (FLUSH). Mesaj: „Gata — repornește”.
3. Dacă ceva pică la mijloc: fișierele vechi rămân (stick-ul pornește în continuare).

**Fișiere:** `user/update/` sau comandă în shell, `kernel/src/fs/fat32.rs` (redenumire, dacă lipsește), driverul USB (FLUSH).

**Test:** scenariul `update` cu un server HTTPS local care servește un Release de test; după rulare, fișierele de pe discul de
test se verifică pe gazdă (sume). Pe laptop: testul lui Adrian.

**Riscuri:** stick scos la mijloc; memorie (initrd-ul are câțiva MB); FAT32 pe stick fără scriere sigură.

**Surse:** documentația publică GitHub (Releases, redirecționări), RFC 9110 (HTTP).

**Notă (P6-07, 2026-10-21):** depozitul `cyber-universe` e **privat**, deci Release-urile nu se descarcă fără autentificare.
Release-ul nu se numește `ultima`, ci `os-<număr>` marcat *Latest*: descărcarea merge prin API (`GET /repos/…/releases/latest`
→ `assets[].url` cu `Accept: application/octet-stream` + antetul `Authorization` → redirecționare către
`objects.githubusercontent.com`), cu tokenul din `/usb/github.token` (același ca la P6-09; drept de citire e de ajuns).
`tools/check-release.sh` face exact acești pași pe gazdă. Dacă Adrian face depozitul public, tokenul nu mai e necesar.

**Realizat (2026-10-22, sesiunea de la 02:40):** `/bin/actualizeaza` (vezi `user/README.md`), apelurile de sistem
`rename` (33) și `sync` (34), `rename`/`flush` în FAT32 (+ un cache de un sector pentru FAT, ca fișierele de mai mulți MiB
să nu ceară o citire de disc pe fiecare cluster), SYNCHRONIZE CACHE la stick-ul USB, butonul „Actualizeaza” în Setări,
`cyber.rw` în imaginea de stick și în Release. Scenariul `update` + `tools/update-test-server.py` + `tools/after-update.sh`.
Pe laptop rămâne de verificat de Adrian (`github.token` pe stick).
