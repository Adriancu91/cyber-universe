# P6-09 — Trimitere pe GitHub din OS

**Scop:** din OS se poate pune un fișier într-un depozit GitHub (de ex. notițe sau rezultatele unui test).

**Pași**
1. Tokenul se citește din `/usb/github.token` (fine-grained, doar pentru depozitul ales). Niciodată în repo, jurnal sau pe ecran.
2. `PUT /repos/{owner}/{repo}/contents/{cale}` cu conținutul în base64 (scris de noi), mesajul commit-ului și `sha`-ul
   versiunii vechi (citit cu `GET` înainte, dacă fișierul există).
3. Comanda `gh-trimite <fisier> <owner/repo> <cale>` și o unealtă pentru Claude (cu confirmare, ca la P6-06).

**Fișiere:** `user/ghpush/`, `json/` (P6-03), scenariu de test cu server local.

**Test:** scenariul `ghpush` cu un server HTTPS de test care imită API-ul și verifică cererea (antete, JSON, base64).

**Surse:** documentația publică GitHub REST API (Contents), RFC 4648 (base64).
