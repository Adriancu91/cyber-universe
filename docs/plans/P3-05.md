# P3-05 — Controler USB XHCI: pornire și enumerarea dispozitivelor

**Scop:** nucleul vede dispozitivele USB conectate (tastatură, stick) prin controlerul XHCI.

**Pași**
1. PCI clasa 0c:03:30, BAR0; preluarea de la BIOS (USB Legacy Support), reset.
2. DCBAA, inelul de comenzi, inelul de evenimente (ERST), interruptere; pornire controler.
3. Porturi: detectare conectare, reset port, `Enable Slot`, `Address Device`, descriptorii de dispozitiv și configurație.
4. Listă de dispozitive USB în jurnal + comanda `lsusb`.

**Fișiere:** `kernel/src/drivers/usb/xhci.rs`, `kernel/src/drivers/usb/mod.rs`, README.

**Test:** scenariu `usb-enum`: QEMU cu `-device qemu-xhci -device usb-kbd -device usb-storage,...` → jurnalul arată
ambele dispozitive cu clasa corectă (HID, Mass Storage).

**Riscuri:** e cel mai complex driver de până acum; împarte în pași mici, fiecare cu test. Controlerele reale au „quirks” (Intel: rutare porturi EHCI→XHCI).

**Surse:** eXtensible Host Controller Interface for USB (xHCI) Specification (Intel, publică); USB 2.0/3.x Specification (descriptori).
