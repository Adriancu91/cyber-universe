# P6-84 — C-114: un singur stick de test (fără Rufus), pe stick-ul FAT32 mare

**Scop:** la testul pe placă, Adrian folosește un singur stick: sistemul de test (cel care poate scrie în placă după „DA”)
copiat ca fișiere pe stick-ul FAT32 mare, lângă `firmware\`, `kronos\` și `github.token`. Stick-ul normal CYBER-UNIV
(fără scriere în placă) rămâne pentru folosirea obișnuită — separarea de siguranță se păstrează.

**Pași**
1. `tools/release-files.sh`: arhiva `stick-test-complet.zip` în Release = toate fișierele din partiția FAT a imaginii
   `cyber-universe-gpu-scrie-usb.img` (EFI, boot, cyber.rw, kronos/mic_q8_0.kgr) + `VERSIUNE` + `CITESTE.txt`; verificat că
   nucleul din arhivă e cel `gpu-scrie`; trecută în `SHA256SUMS`.
2. `tools/windows/STICK-TEST-CITESTE.txt`: pașii pentru Adrian (prima dată / actualizare; ce nu se atinge).
3. `tools/build.sh`: cu `test-usb` + `test-fat-mare`, fișierele imaginii se copiază și pe stick-ul de 64 GiB.
4. Scenariul `stick-complet`: QEMU pornește DE PE stick-ul FAT32 de 64 GiB (fără tabelă de partiții), `/usb` = acel stick,
   jurnalul de 800 de rânduri scris ca la P6-83; `tools/after-stick-complet.sh`: `fsck.fat` curat + fișierele sistemului la locul lor.
5. `docs/USB.md`: secțiunea pentru Adrian.

**Fișiere:** `tools/release-files.sh`, `tools/build.sh`, `tools/windows/STICK-TEST-CITESTE.txt`, `tools/after-stick-complet.sh`,
`tests/scenarios.txt`, `docs/USB.md`.

**Test:** `tools/test.sh stick-complet fat-mare usb`; `tools/build.sh --usb && tools/build.sh --gpu-scrie --usb && tools/release-files.sh`
(arhiva are EFI/BOOT/BOOTX64.EFI, boot/kernel = nucleul gpu-scrie, cyber.rw, VERSIUNE); CI verde → Release cu arhiva.

**Riscuri:** Windows formatează stick-urile mari uneori cu tabelă MBR, nu fără tabelă — OS-ul citește ambele (testat la `usb-floppy`
și `usb-disk`); un firmware UEFI vechi care nu pornește de pe un stick de 64 GB → rămâne varianta cu două stick-uri.
Pe Kingston netestat.

**Surse:** specificația UEFI (pornire de pe mediu FAT32 amovibil, `EFI/BOOT/BOOTX64.EFI`), `docs/USB.md` varianta B.
