# P1-02 — GDT și TSS

**Scop:** tabela proprie de segmente (GDT) cu segmente de nucleu și de utilizator, plus TSS cu stive de urgență.

**Pași**
1. `kernel/src/arch/x86_64/gdt.rs`: intrări null, cod nucleu (64-bit), date nucleu, date utilizator, cod utilizator, TSS (16 octeți).
   Ordinea pentru utilizator (date înainte de cod) pregătește `sysret` din Faza 2.
2. TSS: stivă IST[0] de 16 KiB pentru double fault.
3. Încărcare cu `lgdt`, reîncărcare `CS` (far return), `SS`/`DS`, apoi `ltr`.
4. Opțional: crate-ul `x86_64` 0.15.5 pentru structuri; decizia se notează în DECISIONS.

**Fișiere:** `kernel/src/arch/x86_64/gdt.rs`, `kernel/src/arch/x86_64/mod.rs`.

**Test:** după încărcare, nucleul citește `CS` și `TR` și le afișează; `test.sh` verifică valorile așteptate (ex. `CS=0x08`).

**Riscuri:** triple fault fără mesaj dacă GDT e greșită → rulează QEMU cu `-d int,cpu_reset -no-reboot` pentru diagnostic.

**Surse:** Intel SDM Vol. 3A cap. 3 și 7; OSDev Wiki „GDT”, „TSS”.
